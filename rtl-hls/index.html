BANK 11부 RTL 설계

레지스터 단위로 생각하는 법부터 서로 다른 클럭 사이의 신호까지.

  1. U01RTL로 생각하기

    클럭 엣지마다 레지스터가 한꺼번에 바뀐다는 감각을 익히고, = 와 <= 의 차이를 회로로 확인합니다.

    레지스터와 조합 논리, if/case가 되는 회로, 시뮬레이션과 합성

    1장 열기
  2. U02타이밍: 회로는 얼마나 빨리 돌 수 있나

    전파 지연, setup/hold, 크리티컬 패스, clock skew를 직접 조절해 보며 최대 클럭을 구합니다.

    setup/hold, 크리티컬 패스, LUT 단 수, 타이밍 리포트

    2장 열기
  3. U03FSMD: 컨트롤러와 데이터패스

    Mealy/Moore FSM에 데이터패스를 붙여 숫자를 계산하고, 큰 FSM이 작은 FSM을 부리는 구조를 봅니다.

    FSMD, ASMD 설계 절차, 상태 인코딩, 테스트벤치

    3장 열기
  4. U04파이프라이닝

    레지스터를 끼워 넣어 클럭을 올리는 대신 무엇을 내주는지 따져 보고, valid/ready로 흐름을 멈추고 이어 가는 법을 봅니다.

    latency와 throughput, valid/ready, 되먹임, 스키드 버퍼

    4장 열기
  5. U05동기와 비동기

    리셋, 서로 다른 클럭 사이의 신호, 메타스테이빌리티, 그레이 코드와 비동기 FIFO를 다룹니다.

    메타스테이빌리티, 그레이 코드, 비동기 FIFO, 펄스 넘기기, 클럭 enable

    5장 열기
BANK 22부 HLS

C 코드가 회로가 되는 과정부터 루프, 메모리, 작업 병렬, 수 표현까지. 1부의 FSMD와 파이프라이닝을 알고 보면 지시어가 왜 그렇게 동작하는지 보입니다.

  1. U06HLS: C가 회로가 되는 과정

    식을 직접 입력하고 목표 클럭을 정해 DFG, 스케줄링, 체이닝, 바인딩을 거쳐 FSM과 데이터패스가 만들어지는 과정을 봅니다.

    DFG, 스케줄링, 체이닝, 분기, 비트 폭, 검증 흐름

    6장 열기
  2. U07HLS 루프 지시어

    PIPELINE, UNROLL, ARRAY_PARTITION을 바꿔 가며 II와 latency가 어떻게 변하는지 봅니다.

    PIPELINE, UNROLL, 코드 재구성, 중첩 루프

    7장 열기
  3. U08메모리와 의존성

    배열이 어떤 메모리가 되는지, 한 사이클에 여러 개를 읽으려면 어떻게 쪼개야 하는지, 배열을 통한 의존성이 II를 어떻게 막는지 봅니다.

    BRAM과 분할, 2차원 dim, 히스토그램, DEPENDENCE

    8장 열기
  4. U09작업 병렬과 스트리밍

    함수와 루프를 겹쳐 돌리는 DATAFLOW, ping-pong 버퍼와 스트림, line buffer로 영상을 흘려 처리하는 법을 봅니다.

    task interval, DATAFLOW, ping-pong, 스트림, line buffer

    9장 열기
  5. U10수 표현과 DSP 예제

    2의 보수와 고정소수점, 곱셈 없이 삼각함수를 구하는 CORDIC, 같은 FIR 필터를 RTL과 HLS로 만든 비교까지 다룹니다.

    2의 보수, 고정소수점, CORDIC, FIR 비트 증가

    10장 열기
BANK 33부 실습 프로젝트

1·2부를 모두 엮어 손글씨 숫자를 읽는 작은 신경망 가속기를 만듭니다.

  1. U11시스톨릭 배열

    FIR의 곱셈기 사슬을 격자로 펼쳐 행렬 곱을 하는 배열을 만들고, 타일링과 배치가 속도를 어떻게 정하는지 봅니다.

    PE, skew, 타일링, 데이터 재사용, 시스톨릭 정렬

    11장 열기
  2. U12미니 TPU로 숫자 인식

    손으로 그린 숫자를 int8 신경망과 8×8 시스톨릭 배열로 읽는 작은 가속기를 한 사이클씩 돌려 봅니다.

    int8 양자화, 비트 수와 정확도, BNN, 대역폭

    12장 열기
HLS 장의 수치와 미니 TPU의 사이클 수는 원리를 보여 주기 위한 단순화된 모델이며, 실제 도구의 결과와는 다를 수 있습니다.
