수 표현과 DSP 예제

2의 보수와 고정소수점, 곱셈 없이 삼각함수를 구하는 CORDIC, 같은 FIR 필터를 RTL과 HLS로 만든 비교까지 다룹니다.

10.12의 보수와 고정소수점

하드웨어의 수는 결국 비트 묶음입니다. 같은 8비트 11110100도 어떻게 읽기로 약속하느냐에 따라 244가 되기도, −12가 되기도, −0.75가 되기도 합니다.

  • 부호 없는 정수: 비트마다 128, 64, …, 1의 무게를 더합니다.
  • 2의 보수: 맨 위 비트의 무게만 −128로 바꿉니다. 덧셈 회로를 그대로 쓸 수 있어서 거의 모든 하드웨어가 이 방식을 씁니다.
  • 고정소수점: 2의 보수 정수를 2f로 나눈 값으로 읽습니다. 소수점 위치(f)는 하드웨어에 따로 저장되지 않고, 설계자가 정한 약속일 뿐입니다. 그래서 덧셈, 곱셈 회로는 정수와 똑같습니다.

HLS에서는 ap_fixed<W, I>로 씁니다. W는 전체 비트, I는 소수점 위쪽 비트 수(부호 포함)입니다. 실수를 고정소수점에 넣을 때 생기는 두 가지 문제, 즉 표현할 수 없는 자리를 어떻게 버릴지(반올림)와 범위를 넘으면 어떻게 할지(넘침)도 타입에 정해 둡니다.

기본값(버림, 감기)은 회로가 가장 작지만, 범위를 넘으면 큰 양수가 갑자기 음수가 됩니다. 영상이나 오디오처럼 넘침이 눈에 띄는 곳에서는 포화를 씁니다. 대신 비교기와 MUX가 조금 더 듭니다. 곱셈하면 비트가 두 배로, 덧셈하면 한 비트 늘어난다는 것(6.5)은 고정소수점에서도 같습니다. 소수부 비트 수는 곱하면 더해지고, 더할 때는 큰 쪽에 맞춥니다.

부동소수점(float)도 합성할 수 있지만, 덧셈 하나에 수백 LUT와 몇 사이클의 지연이 듭니다(7장의 덧셈 4사이클). 값의 범위를 알 수 있으면 고정소수점이 훨씬 작고 빠릅니다.

10.2CORDIC: 곱셈 없이 삼각함수 구하기

사인과 코사인을 하드웨어로 구하는 고전적인 방법이 CORDIC입니다. 벡터 (1, 0)을 목표 각도까지 회전시키는데, 아무 각도나 돌리는 대신 tan이 1, 1/2, 1/4, 1/8, …인 각도(45°, 26.6°, 14.0°, 7.1°, …)만큼만 왼쪽 또는 오른쪽으로 돌립니다. 이런 각도로 돌리는 계산은 곱셈 없이 시프트와 덧셈만으로 됩니다.

x' = x − d·y·2−i,　y' = y + d·x·2−i,　z' = z − d·atan(2−i)　(d = z의 부호)

z는 아직 남은 각도입니다. 매번 남은 각도 쪽으로 돌리다 보면 z는 0에 가까워지고, 벡터는 목표 각도를 가리키게 됩니다. 돌릴 때마다 벡터 길이가 조금씩 늘어나지만, 반복 횟수가 정해지면 늘어나는 비율도 정해지므로 처음 벡터를 그만큼 줄여서(약 0.6073) 시작합니다.

반복 한 번에 비트 하나 정도의 정밀도가 늘어나지만, 고정소수점의 소수부 비트보다 더 정밀해질 수는 없습니다(오차 그래프가 바닥에서 평평해지는 지점). 반복 횟수와 비트 폭을 함께 정해야 하는 이유입니다. 하드웨어로는 반복을 모두 펼쳐 단마다 레지스터를 둔 파이프라인(매 사이클 결과 하나)으로 만들 수도 있고, 한 단을 N번 돌려 쓰는 작은 회로(N사이클에 결과 하나)로 만들 수도 있습니다. 7장의 UNROLL과 PIPELINE이 바로 이 선택입니다.

10.3FIR 필터

FIR(Finite Impulse Response) 필터는 최근 입력 몇 개에 계수를 곱해 더하는, 디지털 신호 처리에서 가장 흔한 회로입니다. 이 장에서는 계수가 h = [1, 3, 3, 1]인 4탭 필터를 씁니다. 신호를 부드럽게 만드는 저역 통과 필터입니다.

y[n] = h[0]·x[n] + h[1]·x[n−1] + h[2]·x[n−2] + h[3]·x[n−3]

지금까지 배운 것을 모두 써서 같은 필터를 세 가지로 만들어 비교합니다.

  • A. HLS, 지시어 없음: C 코드를 그대로 합성.
  • B. HLS, 지시어 추가: 함수 전체에 PIPELINE II=1, 시프트 배열에 ARRAY_PARTITION complete.
  • C. RTL 직접 설계: 전치형(transposed) 구조로 손으로 짠 Verilog.

A는 C 코드의 루프를 그대로 따라가서 곱셈기 하나를 네 번 돌려 씁니다. B는 함수에 PIPELINE을 걸면 도구가 안쪽 루프를 모두 펼치고, 배열을 레지스터로 쪼개 네 곱셈을 동시에 합니다. 합하는 순서는 도구가 정하고, 중간에 파이프라인 레지스터도 알아서 넣습니다. C는 곱한 값을 레지스터 사슬을 따라 더해 나가는 구조라서, 어느 레지스터 사이에도 곱셈 하나와 덧셈 하나밖에 없습니다.

계수가 상수라면 3·x는 (x << 1) + x로 바꿀 수 있습니다. 상수 곱셈은 합성기와 HLS 도구 모두 시프트와 덧셈으로 바꾸는 경우가 많아서, 실제로는 곱셈기(DSP)가 하나도 쓰이지 않을 수도 있습니다.

10.4고정소수점 FIR: 비트는 얼마나 필요한가

앞에서는 계수를 정수 [1, 3, 3, 1]로 골라 문제를 피했습니다. 실제 필터의 계수는 0.07, 0.24 같은 소수이고, 입력도 ADC에서 나온 몇 비트짜리 값입니다. 이때 정해야 할 것이 셋입니다.

  • 계수 비트 수: 적으면 계수가 반올림되어 필터 모양 자체가 조금 변합니다.
  • 누산기 비트 수: 곱 하나가 (입력 비트 + 계수 비트)이고, N개를 더하면 log2N비트가 더 늘 수 있습니다. 이보다 작으면 넘칩니다.
  • 출력 비트 수: 누산기를 다음 단으로 넘기기 전에 잘라 냅니다. 자른 만큼 잡음이 생깁니다.

대략 비트 하나를 늘릴 때마다 신호 대 잡음비(SNR)가 6 dB씩 좋아집니다. 가장 적은 쪽 비트가 전체 품질을 정하므로, 한쪽만 크게 늘리는 것은 낭비입니다.

10.5대칭 계수 접기

저역 통과 필터처럼 많은 FIR 필터는 계수가 좌우 대칭입니다(h[0]=h[3], h[1]=h[2]). 그러면 같은 계수를 곱할 두 입력을 먼저 더하고 한 번만 곱하면 됩니다.

// 곱셈 4번
acc = h[0]*x[0] + h[1]*x[1] + h[1]*x[2] + h[0]*x[3];
// 대칭을 이용하면 곱셈 2번
acc = h[0]*(x[0] + x[3]) + h[1]*(x[1] + x[2]);

FPGA의 DSP 블록에는 곱셈기 앞에 덧셈기(pre-adder)가 들어 있어서, 점선 상자 하나가 DSP 하나에 그대로 들어갑니다. 대칭 N탭 필터는 곱셈기 N/2개로 됩니다. HLS 도구가 이 모양을 알아서 찾기도 하지만, 코드를 위처럼 쓰면 확실합니다.

10.6DFT는 행렬-벡터 곱이다

이산 푸리에 변환(DFT)은 신호 N개를 주파수 성분 N개로 바꿉니다. 식을 보면 정해진 계수(회전 인자) 행렬과 입력 벡터의 곱입니다.

X[k] = Σn x[n] · Wkn,　W = e−j2π/N　→　X = W · x (N×N 행렬 × 벡터)

그래서 DFT를 HLS로 옮기는 일은 7.5의 중첩 루프 행렬-벡터 곱, 8장의 배열 분할(계수 표를 행과 열 중 어느 방향으로 쪼갤지), 11장의 시스톨릭 배열과 똑같은 고민이 됩니다(책 4장). 곱셈은 N²번이고, 9.4의 FFT는 같은 결과를 N log2N번으로 얻는 재구성입니다.

다른 점은 값이 복소수라는 것입니다. 복소수 곱 (a+jb)(c+jd) = (ac−bd) + j(ad+bc)는 그대로 하면 곱셈 4번, 덧셈 2번입니다. 순서를 바꾸면 곱셈 3번, 덧셈 5번으로 됩니다. 곱셈기(DSP)가 덧셈기보다 훨씬 귀하므로 흔히 쓰는 기법입니다(책 2.11).

k1 = c * (a + b);
k2 = a * (d - c);
k3 = b * (c + d);
re = k1 - k3;          // = ac - bd
im = k1 + k2;          // = ad + bc

10.7그래서 언제 무엇을 쓰나

RTL은 사이클과 레지스터를 하나하나 정할 수 있어서, 가장 작고 빠른 회로를 만들 수 있습니다. 대신 알고리즘을 조금만 바꿔도 코드를 크게 고쳐야 합니다. HLS는 알고리즘을 C로 빠르게 바꿔 보고, 지시어만 바꿔서 여러 설계(설계 공간)를 탐색하기 좋습니다. 대신 결과가 원하는 대로 나오게 하려면, 도구가 어떤 하드웨어를 만들지 머릿속에 그릴 수 있어야 합니다.

결국 두 방식은 경쟁 관계가 아닙니다. 이 강의에서 배운 레지스터, 타이밍, FSMD, 파이프라인, 핸드셰이크는 HLS 리포트를 읽고 지시어를 고를 때 그대로 쓰는 지식입니다.

이 장의 요점
  • 고정소수점은 정수에 소수점 위치를 약속한 것입니다. 넘침과 반올림 방식을 타입에 정합니다.
  • CORDIC은 시프트와 덧셈만으로 회전합니다. 반복 수와 비트 폭을 함께 정합니다.
