10장

미니 TPU로 숫자 인식

손으로 그린 숫자를 int8 신경망과 8×8 시스톨릭 배열로 읽는 작은 가속기를 한 사이클씩 돌려 봅니다.

10.1숫자를 읽는 작은 신경망

이 장에서 가속할 대상은 8×8 픽셀 손글씨 숫자를 읽는 신경망입니다. 픽셀 값은 0~16이고, 입력 64개 → 은닉 뉴런 16개 → 출력 10개(0~9 각 숫자의 점수)인 아주 작은 다층 퍼셉트론(MLP)입니다. 학습은 미리 해 두었습니다(scikit-learn 손글씨 숫자 데이터).

h = ReLU(x · W1 + b1)　　z = h · W2 + b2　　답 = z가 가장 큰 숫자

x는 길이 64 벡터, W1은 64×16 행렬, W2는 16×10 행렬입니다. 즉 이 신경망의 계산은 거의 전부 벡터와 행렬의 곱이고, 9장의 시스톨릭 배열이 잘하는 바로 그 일입니다. ReLU는 음수를 0으로 만드는 것뿐이라 회로로는 비교기 하나입니다.

10.2실수 대신 8비트 정수로

학습은 실수(float)로 했지만, 가속기는 보통 int8로 계산합니다. 곱셈기 크기는 대략 비트 수의 제곱에 비례하므로 8비트 곱셈기는 32비트 실수 곱셈기보다 훨씬 작고, 가중치를 담는 메모리도 4분의 1로 줄어듭니다.

  • 가중치에 적당한 배율을 곱해 −127~127 정수로 반올림해 둡니다.
  • 8비트 × 8비트 곱을 64개 더하면 8비트를 훌쩍 넘으므로, 누산은 32비트로 합니다.
  • 다음 층에 넘기기 전에 다시 0~127로 줄입니다(재양자화). 실수 배율을 곱하는 대신 정수를 곱하고 오른쪽으로 시프트합니다. ReLU는 0 아래를 자르는 것으로 같이 처리됩니다.

이 신경망 한 번에 필요한 곱셈은 64×16 + 16×10 = 1,184번입니다. MAC 하나로 하면 1,184사이클 남짓이 걸립니다. 이제 이걸 8×8 시스톨릭 배열에 올려 보겠습니다.

10.3미니 TPU의 구조

  • 입력 버퍼: 이번 층의 입력 벡터(들)를 담습니다.
  • 가중치 메모리: W1, W2를 8×8 타일 단위로 꺼내 배열에 싣습니다.
  • 8×8 시스톨릭 배열: 9장의 PE 64개. 가중치 고정 방식입니다.
  • 누산기: K 방향으로 나뉜 타일들의 부분합을 32비트로 모읍니다. 1층은 K=64라 타일 8개 분량을 더해야 합니다.
  • 후처리기: 바이어스 더하기, ReLU, 재양자화. 결과는 다시 입력 버퍼로 가서 다음 층의 입력이 됩니다.
  • 컨트롤러: 3장의 FSMD처럼 “타일 싣기 → 흘리기 → 다음 타일 → 후처리 → 다음 층” 순서를 지휘합니다.

1층(64×16)은 8×2 = 16타일, 2층(16×10)은 2×2 = 4타일입니다. 2층 출력은 10개라 두 번째 열 타일에서는 8열 중 2열만 일합니다.

10.4HLS로 쓴다면

같은 1층을 HLS로 쓰면 이렇습니다. 7장의 지시어를 그대로 씁니다.

void dense1(const unsigned char x[64], unsigned char h[16]) {
  int acc[16];
#pragma HLS ARRAY_PARTITION variable=acc complete
#pragma HLS ARRAY_PARTITION variable=W1 complete dim=2
  for (int n = 0; n < 16; n++) acc[n] = b1[n];
  for (int k = 0; k < 64; k++) {
#pragma HLS PIPELINE II=1
    for (int n = 0; n < 16; n++)        // 자동으로 펼쳐져 곱셈기 16개
      acc[n] += x[k] * W1[k][n];
  }
  for (int n = 0; n < 16; n++) {
    int q = (acc[n] * M1 + (1 << 15)) >> 16;   // 재양자화
    h[n] = q < 0 ? 0 : (q > 127 ? 127 : q);     // ReLU + 자르기
  }
}

이 코드는 x[k] 하나를 곱셈기 16개에 동시에 뿌리는 구조(8장 전치형 FIR과 같은 브로드캐스트)를 만들고, 64사이클 남짓이면 1층이 끝납니다. 이 크기에서는 오히려 이쪽이 단순하고 빠릅니다. 시스톨릭 배열이 빛나는 것은 행렬과 배치가 커서 브로드캐스트 선과 메모리 대역폭이 문제가 되는 규모입니다. HLS로 진짜 시스톨릭 구조를 만들려면 PE를 함수로 쓰고 PE 사이를 스트림으로 잇는 식으로 구조를 직접 적어 줘야 합니다.

과제로 확장하기 9장의 PE를 Verilog로 쓰고 4×4 배열을 연결해 실험 9-1의 결과를 테스트벤치로 재현하기.
위 HLS 코드에서 바깥 루프를 UNROLL factor=2로 바꾸면 곱셈기 수와 사이클이 어떻게 변할지 예측하고 리포트로 확인하기.
은닉 뉴런을 32개로 늘리면 미니 TPU의 타일 수와 사이클이 어떻게 변할지 계산하기.
