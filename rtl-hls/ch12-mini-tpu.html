12장

미니 TPU로 숫자 인식

손으로 그린 숫자를 int8 신경망과 8×8 시스톨릭 배열로 읽는 작은 가속기를 한 사이클씩 돌려 봅니다.

12.1숫자를 읽는 작은 신경망

이 장에서 가속할 대상은 8×8 픽셀 손글씨 숫자를 읽는 신경망입니다. 픽셀 값은 0~16이고, 입력 64개 → 은닉 뉴런 16개 → 출력 10개(0~9 각 숫자의 점수)인 아주 작은 다층 퍼셉트론(MLP)입니다. 학습은 미리 해 두었습니다(scikit-learn 손글씨 숫자 데이터).

h = ReLU(x · W1 + b1)　　z = h · W2 + b2　　답 = z가 가장 큰 숫자

x는 길이 64 벡터, W1은 64×16 행렬, W2는 16×10 행렬입니다. 즉 이 신경망의 계산은 거의 전부 벡터와 행렬의 곱이고, 11장의 시스톨릭 배열이 잘하는 바로 그 일입니다. ReLU는 음수를 0으로 만드는 것뿐이라 회로로는 비교기 하나입니다.

12.2실수 대신 8비트 정수로

학습은 실수(float)로 했지만, 가속기는 보통 int8로 계산합니다. 곱셈기 크기는 대략 비트 수의 제곱에 비례하므로 8비트 곱셈기는 32비트 실수 곱셈기보다 훨씬 작고, 가중치를 담는 메모리도 4분의 1로 줄어듭니다.

  • 가중치에 적당한 배율을 곱해 −127~127 정수로 반올림해 둡니다.
  • 8비트 × 8비트 곱을 64개 더하면 8비트를 훌쩍 넘으므로, 누산은 32비트로 합니다.
  • 다음 층에 넘기기 전에 다시 0~127로 줄입니다(재양자화). 실수 배율을 곱하는 대신 정수를 곱하고 오른쪽으로 시프트합니다. ReLU는 0 아래를 자르는 것으로 같이 처리됩니다.

이 신경망 한 번에 필요한 곱셈은 64×16 + 16×10 = 1,184번입니다. MAC 하나로 하면 1,184사이클 남짓이 걸립니다. 이제 이걸 8×8 시스톨릭 배열에 올려 보겠습니다.

12.3미니 TPU의 구조

  • 입력 버퍼: 이번 층의 입력 벡터(들)를 담습니다.
  • 가중치 메모리: W1, W2를 8×8 타일 단위로 꺼내 배열에 싣습니다.
  • 8×8 시스톨릭 배열: 11장의 PE 64개. 가중치 고정 방식입니다.
  • 누산기: K 방향으로 나뉜 타일들의 부분합을 32비트로 모읍니다. 1층은 K=64라 타일 8개 분량을 더해야 합니다.
  • 후처리기: 바이어스 더하기, ReLU, 재양자화. 결과는 다시 입력 버퍼로 가서 다음 층의 입력이 됩니다.
  • 컨트롤러: 3장의 FSMD처럼 “타일 싣기 → 흘리기 → 다음 타일 → 후처리 → 다음 층” 순서를 지휘합니다.

1층(64×16)은 8×2 = 16타일, 2층(16×10)은 2×2 = 4타일입니다. 2층 출력은 10개라 두 번째 열 타일에서는 8열 중 2열만 일합니다.

12.4HLS로 쓴다면

같은 1층을 HLS로 쓰면 이렇습니다. 7장의 지시어를 그대로 씁니다.

void dense1(const unsigned char x[64], unsigned char h[16]) {
  int acc[16];
#pragma HLS ARRAY_PARTITION variable=acc complete
#pragma HLS ARRAY_PARTITION variable=W1 complete dim=2
  for (int n = 0; n < 16; n++) acc[n] = b1[n];
  for (int k = 0; k < 64; k++) {
#pragma HLS PIPELINE II=1
    for (int n = 0; n < 16; n++)        // 자동으로 펼쳐져 곱셈기 16개
      acc[n] += x[k] * W1[k][n];
  }
  for (int n = 0; n < 16; n++) {
    int q = (acc[n] * M1 + (1 << 15)) >> 16;   // 재양자화
    h[n] = q < 0 ? 0 : (q > 127 ? 127 : q);     // ReLU + 자르기
  }
}

이 코드는 x[k] 하나를 곱셈기 16개에 동시에 뿌리는 구조(10장 전치형 FIR과 같은 브로드캐스트)를 만들고, 64사이클 남짓이면 1층이 끝납니다. 이 크기에서는 오히려 이쪽이 단순하고 빠릅니다. 시스톨릭 배열이 빛나는 것은 행렬과 배치가 커서 브로드캐스트 선과 메모리 대역폭이 문제가 되는 규모입니다. HLS로 진짜 시스톨릭 구조를 만들려면 PE를 함수로 쓰고 PE 사이를 스트림으로 잇는 식으로 구조를 직접 적어 줘야 합니다.

과제로 확장하기 11장의 PE를 Verilog로 쓰고 4×4 배열을 연결해 실험 9-1의 결과를 테스트벤치로 재현하기.
위 HLS 코드에서 바깥 루프를 UNROLL factor=2로 바꾸면 곱셈기 수와 사이클이 어떻게 변할지 예측하고 리포트로 확인하기.
은닉 뉴런을 32개로 늘리면 미니 TPU의 타일 수와 사이클이 어떻게 변할지 계산하기.

12.5비트 수를 더 줄이면

12.2에서는 8비트로 바꿔도 정확도가 거의 그대로였습니다. 비트를 더 줄이면 곱셈기와 메모리가 더 작아지지만 어디선가 정확도가 무너집니다. 그 지점을 직접 찾아봅시다. 양자화의 핵심은 배율(scale)을 정하는 것입니다.

  • 가중치: 가장 큰 절댓값이 정수 최댓값(8비트면 127)이 되도록 배율 sw = max|w| / (2b−1−1)을 정하고, w/sw를 반올림합니다. 배율을 층 전체에 하나 쓰면 per-tensor, 출력 뉴런마다 따로 쓰면 per-channel입니다.
  • 활성값: 미리 데이터 몇백 개를 넣어 보고(보정, calibration) 은닉층 값이 대개 어디까지 커지는지 재서 배율을 정합니다. ReLU 뒤라 음수가 없으므로 부호 없는 정수를 씁니다.
  • 12.2의 771과 16: 두 배율을 곱한 실수 비율 sx·sw/sh를 “정수 771을 곱하고 16비트 오른쪽으로 민다”로 근사한 것입니다.

12.61비트까지: 이진 신경망과 popcount

가중치와 활성값을 모두 +1과 −1 두 값으로만 쓰는 신경망을 이진 신경망(BNN)이라고 합니다. +1을 비트 1, −1을 비트 0으로 저장하면, 두 수의 곱은 “같으면 +1, 다르면 −1”이므로 XNOR 게이트 하나가 됩니다. 그리고 N개 곱의 합은 1의 개수만 세면 구할 수 있습니다.

Σ ak·wk = 2 × popcount(XNOR(a, w)) − N

곱셈기가 사라지고 XNOR와 1의 개수를 세는 회로(popcount)만 남으므로, 같은 FPGA에 MAC을 수십 배 더 넣을 수 있습니다. 대신 위 실험에서 본 것처럼 정확도가 크게 떨어지므로, 실제 BNN은 층을 넓히고 처음부터 이진 값으로 학습시킵니다.

12.7BNN 층 하나의 하드웨어

이진 신경망의 뉴런 하나는 두 부분으로 끝납니다(책 12.5).

  • popcount: XNOR 결과 N비트에서 1의 개수를 셉니다. 1비트끼리 더하고, 그 결과끼리 더하는 덧셈 나무로 만듭니다. 단마다 비트가 하나씩 늘어 log2N단이면 됩니다.
  • 임계값 비교: 보통 신경망은 이 뒤에 배치 정규화(평균을 빼고 나누고 곱하고 더하기)와 활성화가 붙습니다. 이진 신경망은 출력도 ±1이므로, 이 계산 전체가 “popcount가 어떤 값 T 이상인가” 하나로 합쳐집니다. T는 학습이 끝난 뒤 미리 계산해 둡니다.
γ·(x − μ)/σ + β ≥ 0　⇔　x ≥ μ − β·σ/γ (γ > 0)　→　x = 2·pop − N 이므로 pop ≥ T

뉴런 하나가 곱셈기 없이 XNOR 16개, 작은 덧셈기 15개, 비교기 하나로 끝납니다. 같은 일을 8비트로 하면 곱셈기 16개와 넓은 누산기가 필요합니다. 그래서 같은 FPGA에 BNN 뉴런을 훨씬 많이 넣어 병렬로 돌릴 수 있습니다.

12.8버퍼는 얼마나 크고, 메모리는 얼마나 빨라야 하나

저장할 것크기
W1 (64×16, int8)1,024 B
W2 (16×10, int8)160 B
바이어스, 재양자화 상수약 110 B
그림 한 장 입력 + 은닉층64 + 16 B
누산기 16개 (32비트)64 B

모두 합쳐 1.5 KB가 안 되어 BRAM 한 개에 들어갑니다. 그래서 미니 TPU에서는 가중치를 매번 칩 밖에서 가져올 필요가 없고, 실험 12-2의 시간은 순전히 계산과 싣기 시간이었습니다.

모델이 커지면 이야기가 달라집니다. 가중치 1억 개짜리 모델은 int8로도 100 MB라 칩 안에 들어가지 않습니다. 그림 한 장마다 가중치를 모두 칩 밖에서 가져온다면, 초당 1,000장을 처리하는 데 100 GB/s의 메모리 대역폭이 필요합니다. 그래서 큰 가속기는 배치로 가중치를 여러 입력에 돌려 쓰고(11.5), 비트 수를 줄여 옮길 양 자체를 줄이고(12.5), 메모리를 계산 가까이에 둡니다. 7장의 메모리 포트 문제가 칩 전체 규모로 커진 것입니다.

실제 도구에서는실제로는 학습 중에 양자화를 흉내 내는 방법(quantization-aware training)으로 4비트 이하에서도 정확도를 지키고, 층마다 비트 수를 다르게 쓰기도 합니다. BNN도 처음부터 이진 값으로 학습합니다. 실험 12-3은 학습이 끝난 뒤 비트만 줄인 경우라 실제보다 비관적인 결과입니다.
이 장의 요점
  • 신경망 추론은 대부분 행렬-벡터 곱입니다. 8비트로 곱하고 32비트로 누산합니다.
  • 양자화의 핵심은 배율을 정하는 것입니다. 비트를 너무 줄이면 정확도가 무너집니다.
  • 1비트에서는 곱셈이 XNOR, 덧셈이 popcount가 됩니다.
  • 큰 모델은 메모리 대역폭이 병목입니다. 재사용, 배치, 비트 줄이기로 대응합니다.
